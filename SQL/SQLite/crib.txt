Примеры ключевых слов:

SELECT id, name, age FROM Users – выбирает во всей таблице Users элементы
SELECT name, age FROM Users WHERE id = 5 – выбирает элементы в таблице только если айди (как элемент) равен 5
SELECT COUNT() FROM Users – получает размер таблицы (сколько в ней элементов)
DELETE FROM Users WHERE id = 5 – убирает элемент в таблице если айди равно 5
INSERT INTO Users (name, age) VALUES ('Denis', 15) – добавляет новые элементы в таблицу
DROP TABLE IF EXISTS table; – навсегда удаляет эту таблицу если она существовала 

Для элементов:

INTEGER – значение должно быть целым числом
TEXT – значение должно быть строкой с кодировкой UTF-8, UTF-16 или UTF-16Le
REAL – вещественные числа 
BLOB – двоичные данные (для картинок и т.п)
PRIMARY KEY – делает столбец уникальным индификатором и он автоматически создаётся 

NOT NULL – предотвращает значению быть NULL (пустым)
DEFAULT <value> – ставит значение элемента по умолчанию если он не был указан (например age INTEGER DEFAULT 1)
UNIQUE – гарантирует чтобы все элементы в этом столбце были уникальными (например key TEXT UNIQUE)
CHECK – ограничение для столбца или таблицы: {
  CHECK (age >= 18 AND salary > 0) – Проверка условиями (также есть OR и NOT, а также: !=, ==, <=, >= и т.д)
  CHECK (status IN ('new', 'active', 'closed')) – статус может быть только одним из элементов из списка
  CHECK (LENGTH(phone) = 11) – сверяет длину строки
  CHECK IS NOT NULL – проверить не является ли элемент пустым
  CONSTRAINT Users CHECK (age >= 0) – ограничение на уровне таблицы
}

Функции (Core Functions):

LENGTH(var) – получает количество символов или количество байтов (для бинарников)
LOWER(str) / UPPER(str) – переводят строку в нижний или верхний регистр
TRIM / LTRIM / RTRIM(str) – удаляют пробелы или указанные символы в строке
SUM(column) – вычисляет сумму всех значений в столбце
AVG(column) – вычисляет среднее арифметическое
MIN / MAX(column) – получает наименьшее или наибольшее число в столбце (можно использовать как SELECT MAX(price) FROM products; или так: SELECT product_name, MAX(discount1, discount2) AS best_discount (а потом FROM sales;))

Другие особенности:

Ограничения можно накладывать друг на друга (например age INTEGER DEFAULT 10 NOT NULL)
Штуки по типу NOT NULL это называется правила столбца (ограничение)
Можно сделать комментария с помощью двойного дефиса, как в Lua
По умолчанию можно сделать максимум 2000 столбцов в одной таблице, но его можно из с помощью флага -DSQLITE_MAX_COLUMN=32767 (максимум 32767). Этот флаг невозможно изменить в рантайме
Функции можно использовать двумя способами: агрегатное (поиск в таблице) и скалярное (для условий)
